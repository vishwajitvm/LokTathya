# Project Constraints

## Mandatory Constraints
- Open source
- MIT software license
- Docker
- Free/open-source infrastructure
- Self-hostability
- PostgreSQL/PostGIS preferred
- pgvector preferred initially
- Redis
- Celery
- MinIO for local object storage
- FastAPI
- Next.js
- TypeScript
- Python
- TraceNest
- Mermaid
- Stitch
- Stitch MCP
- Public APIs
- Official-source-first
- Source registry
- Source provenance
- Source versioning
- Historical data
- Model fallback
- Embedding fallback
- Data-quality monitoring
- Evidence-backed AI
- Political neutrality

## Prohibited
- Hard dependency on paid infrastructure
- Fake production data
- Fabricated government records
- Unsupported accusations
- Political persuasion
- Voter profiling
- Private personal data exposure
- Guaranteed election predictions
- Claiming derived metrics are official government ratings
- Claiming a financial discrepancy is automatically corruption/theft
- Hard-coded secrets
- API keys committed to Git
- Arbitrary undocumented architectural decisions
