# Source Registry

This document governs the LokTathya Official Source Registry. It dictates that LokTathya is a source-first civic data platform.

## Authority Levels
- **LEVEL 1**: Official constitutional/statutory/election/government authority
- **LEVEL 2**: Official government department/ministry/agency
- **LEVEL 3**: Official state/UT government authority
- **LEVEL 4**: Official district/local-government authority
- **LEVEL 5**: Official government-hosted dataset/document portal
- **LEVEL 6**: Official public-sector/constitutional/statutory body
- **LEVEL 7**: Secondary authoritative source
- **LEVEL 8**: Non-authoritative/community source
