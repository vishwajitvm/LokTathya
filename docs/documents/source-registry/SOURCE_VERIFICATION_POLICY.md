# Source Verification Policy

Every candidate source must be verified against its responsible official authority.
A source cannot be verified simply because it uses a .gov.in domain or is returned in a Google Search.

**Required Verification Evidence:**
1. Official domain matching known government structures.
2. Cross-linking from other verified Level 1/2 government portals.
3. Explicit "About Us" mapping to a statutory body.

**Statuses:**
DISCOVERED, UNVERIFIED, VERIFIED, ACTIVE, TEMPORARILY_UNAVAILABLE, DEPRECATED, RETIRED, BLOCKED, REJECTED.
