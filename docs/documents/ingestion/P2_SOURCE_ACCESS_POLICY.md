# P2 Source Access Policy

## Purpose
Governs the terms under which official sources are registered and queried by the LokTathya platform.

## Security Diagram
Refer to [ingestion-security.mmd](file:///c:/python/LokTathya/docs/diagrams/06-security/ingestion-security.mmd) for fetch security boundaries.

## Guidelines
- Strict domain-based access limits.
- Compliance with robots.txt directives and explicit rate-limiting policies.
- Circumspection of authentication layers: paywalls and CAPTCHAs are never bypassed programmatically.
