# Data Policy

## Accuracy & Completeness
- Never invent government data.
- If unavailable, explicitly show: DATA UNAVAILABLE.
- If incomplete: INSUFFICIENT DATA.
- If model-generated: MODEL-GENERATED.
- If community submitted: COMMUNITY-REPORTED.

## Separation
- Official data, derived data, model-generated data, and community-submitted information must never be silently mixed.

## Provenance
- Every factual record must be traceable to its source.
- Claim -> Evidence -> Source -> Document -> Version.

## Geographic Coverage
- Create architecture for all Indian states and UTs.
- Adding a new state must not require redesigning the core architecture.
