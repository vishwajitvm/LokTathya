# Design System

Stitch is the visual design source of truth.

## Brand and Visuals
- **Vibe**: Trustworthy, data-driven, civic, modern, professional, transparent, research-grade.
- **Colors**: To be imported from Stitch. Focus on accessibility and clarity.
- **Typography**: Clean, readable sans-serif fonts.
- **Themes**: Support for both light and dark modes.

## Components
- Cards for representatives and projects
- Tables for data grids (e.g. budgets, datasets)
- Charts (Bar, Line, Pie) for financial and election data
- Maps for geospatial visualizations
- Filters for search and faceted navigation
- Badges for data status:
  - OFFICIAL
  - DERIVED
  - MODEL-GENERATED
  - COMMUNITY-REPORTED
  - DATA UNAVAILABLE
  - INSUFFICIENT DATA

## Source Citations & Evidence Indicators
- Every metric/value must have visual indicators linking back to its source.
